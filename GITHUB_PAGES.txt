WAREHOUSE MASTERPRESS — PUBLIKACJA NA GITHUB PAGES

1. Rozpakuj paczkę na komputerze.
2. Otwórz wewnętrzny folder Warehouse-Masterpress.
3. Do katalogu głównego AKTUALNEGO repozytorium prześlij całą zawartość
   tego folderu. Nie przesyłaj samego ZIP-a ani zewnętrznego folderu.
4. Sprawdź na karcie Code, czy w katalogu głównym repozytorium znajduje się
   folder docs, a bezpośrednio w nim index.html oraz folder assets.
5. Dopilnuj, aby pliki znalazły się na gałęzi main.
6. Wejdź w repozytorium: Settings → Pages.
7. W sekcji Build and deployment ustaw Source: Deploy from a branch.
8. Wybierz Branch: main oraz folder: /docs i kliknij Save.
9. Otwórz zakładkę Actions i poczekaj, aż zadanie pages build and deployment
   zakończy się zielonym znacznikiem.
10. Link do aplikacji pojawi się w Settings → Pages.

Folder docs zawiera gotową, zbudowaną aplikację. GitHub nie może publikować
bezpośrednio plików index.html i pages-main.tsx z głównego folderu.

Przy następnych zmianach podmień wszystkie pliki, łącznie z folderem docs.
Wgrywanie nowych plików nie usuwa starych automatycznie, ale stare pliki
w docs/assets nie przeszkadzają, ponieważ index.html wskazuje aktualną wersję.

Plik w .github/workflows służy wyłącznie do ręcznego sprawdzenia kompilacji.
Publikacja strony korzysta z prostszego ustawienia main / docs opisanego wyżej.
